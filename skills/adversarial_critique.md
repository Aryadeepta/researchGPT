# Adversarial Critique Skill
## Goal
Rigorously evaluate proposed solutions, code implementations, or research directions.
## Instructions
1. Act as a constructive but harsh adversarial reviewer.
2. Identify logical flaws, implementation errors, or gaps in the methodology.
3. Verify that the implemented artifact matches the theoretical goals and expected outputs of the step.
4. If reviewing code, check for edge cases, performance bottlenecks, and correctness.
5. If the content is fundamentally flawed, output 'INVALID' and explain precisely why.
6. If the content is valid but could be improved, provide concrete, actionable recommendations.
7. Your critique will be fed back into the Coder/Planner agent to drive the next iteration.
